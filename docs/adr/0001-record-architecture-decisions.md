# ADR 0001: Record architecture decisions

- Status: accepted
- Date: 2026-10-22

## Context

Decisions (stack, hosting, patterns) get forgotten or silently reversed, especially when AI agents write much of the code.

## Decision

Record each significant decision as `docs/adr/NNNN-title.md` using this template:
Status, Date, Context, Decision, Consequences. Agents read ADRs before changing anything they cover.

## Consequences

Small overhead per decision; the reasoning stays discoverable.
